# Inherited voice-tunnel specs (001–029)

These are the specs written for **voice-tunnel**, before the fork into Command Bridge. They document
features that Command Bridge inherited and still runs — the turn log and cursor contract, lanes,
delivery, turn detection, voice quality — so they remain the authoritative record of that behaviour.

They were shelved here on 2026-09-01 so Command Bridge's own spec sequence could start fresh at `001`
(JJ: *"in this new repo everything should be called Command Bridge"* / *"remove the CB prefix on the
specs, just keep the numbers"*). They are **not** renumbered or rewritten — the numbers and text are
the shipped history.

Command Bridge's own specs live one level up, in `specs/`, numbered from `001`.
